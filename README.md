# fileuploader

File upload service built with Clean Architecture in Go.

[![License](https://img.shields.io/badge/License-MIT-success)](https://github.com/minhhoccode111/fileuploader/blob/master/LICENSE)
[![Go Report Card](https://goreportcard.com/badge/github.com/minhhoccode111/fileuploader)](https://goreportcard.com/report/github.com/minhhoccode111/fileuploader)

## Quick start

### Local development

```sh
make compose-up
make run
```

### Integration tests

```sh
make compose-up-integration-test
```

## Project structure

Based on [go-clean-template](https://github.com/evrone/go-clean-template). See the original project for Clean Architecture documentation and details.
