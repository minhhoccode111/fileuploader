# Design records

These files are historical records of how a feature was designed and built, kept
in the order they were written. They are not the current documentation.

- `specs/` — the agreed design for one change, written before implementation.
- `plans/` — the implementation steps that followed the spec.

A record may describe code that has since moved or been replaced. For the
current architecture, commands and conventions, read the repository
[`AGENTS.md`](../../AGENTS.md). For the product overview, read
[`README.md`](../../README.md).
